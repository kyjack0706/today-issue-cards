# 오늘의 화제 이슈 - Free News API 버전

Free News API의 공식 문서 기준으로 API 키/헤더/회원가입 없이 사용합니다.
한국(country=KR), 한국어(language=ko) 조건으로 검색하고 카테고리별 검색어를 사용합니다.

실행:
1. Node.js 18+
2. `npm install`
3. `npm start`
4. `http://localhost:3000`

서버 시작 시 즉시 수집하고 1시간마다 갱신합니다. 7일 지난 기사는 삭제합니다.

주의: API가 제공하는 원문 URL과 데이터 이용조건을 확인한 뒤 서비스 목적에 맞게 사용하세요.
